# Источник SideStore

URL источника:

```text
https://cdn.jsdelivr.net/gh/lionsgroup2013-cell/click-ai-fitness-coach@main/source/apps.json
```

В SideStore откройте **Sources → Add Source** и вставьте этот URL. Затем выберите CLICK AI Coach и нажмите установку.

В источнике размещён неподписанный IPA. SideStore подписывает его вашим Apple ID. Серверные ключи Aggregate в приложение не встроены.
